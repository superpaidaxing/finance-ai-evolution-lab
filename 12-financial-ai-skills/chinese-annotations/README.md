# 金融 AI Skill 中文详细注释总索引

> 本目录为每一个已收录的 `SKILL.md` 提供单独中文注释。原始 skill 保留英文/上游格式，中文注释用于帮助中文读者理解其金融业务含义、AI 工作流、输入输出、可迁移应用和风险边界。

## 如何使用

1. 先从下表按领域找到感兴趣的 skill。
2. 打开对应中文注释文件，先读“这个 skill 是干什么的”和“原始工作流导读”。
3. 再回到 `upstream-snapshots/` 阅读原始 `SKILL.md`。
4. 如果未来要改造成中国银行业场景，优先看注释中的“迁移方向”和“治理边界”。
